# Per-platform boards.local.txt override for the espressif_esp32c5_devkitc_1_n8r4 CI target.
#
# ci-arduino's build_platform.py (--boards-local-txt) installs the most specific match as
# <platform dir>/boards.local.txt before building this example:
#   <example>/.<platform>.boards.local.txt > <example>/boards.local.txt > repo-root file > none
#
# The ESP32-C5-DevKitC-1 builds with the generic Espressif esp32c5 board (ARDUINO_ESP32C5_DEV),
# which other boards (e.g. the LilyGO T-Dongle C5) share. ws_boards.h falls back to the DevKitC
# for a bare ARDUINO_ESP32C5_DEV, but give it a unique define matching its Board ID anyway:
# "esp32c5-devkitc-1-n8r4" -> -DWS_ESPRESSIF_ESP32C5_DEVKITC_1_N8R4. Mirror it in
# platformio.ini build_flags. That board's PSRAM menu sets build.defines, and the menu value wins
# over the board key, so override both PSRAM menu keys (keeping -DBOARD_HAS_PSRAM) as well as the
# board key:
esp32c5.build.defines=-DWS_ESPRESSIF_ESP32C5_DEVKITC_1_N8R4
esp32c5.menu.PSRAM.disabled.build.defines=-DWS_ESPRESSIF_ESP32C5_DEVKITC_1_N8R4
esp32c5.menu.PSRAM.enabled.build.defines=-DBOARD_HAS_PSRAM -DWS_ESPRESSIF_ESP32C5_DEVKITC_1_N8R4
